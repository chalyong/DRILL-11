소년의 상태가 idle 상태에서 'a' 키를 누르면, 소년은 'Auto Run' 상태가 되어야 함.

키 조작 없이도 좌우로 이동해야 한다.

기존의 run 상태보다 속도가 빨라야 하고, 크기도 기존보다 크게 그려야 함

화면의 좌우측 끝에서 자동 방향 전환이 되어야 함


auto run 상태에서 5초 이상 경과시 idle 상태로 돌아감.

auto run 상태에서 방향키 입력시, auto run이 취소되고, 눌린 방향으로 이동하는 run 상태가 되어야 함


중요: 반드시 auto run 상태 클래스를 추가해서 구현해야 함

채점 기준: a 를 누를시 auto run 상태 이동. 5초 이상 경과시 idle 상태로 복귀. auto run 상태에서 속도가 빨라지고, 소년의 크기가 커짐. auto run 좌우측 끝에서 자동 방향 전환.
